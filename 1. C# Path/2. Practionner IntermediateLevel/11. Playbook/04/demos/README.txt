Most photos shown in the course are not included with the demo files because of licensing restrictions. (with the exception of missing.jpg, which is supplied) 

Therefore you'll need to supply your own photos for this demo to run and show the same output as in the course modules.

Add the photos to the Data subfolder under each project, and give the photo names like dog_1_Josie.jpg, dog_2_Bouncy.jpg, dog_3_Lazy.jpg, etc.
